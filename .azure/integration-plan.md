# Integration hand-off / implementation map

- **API:** `server/`; local command `npm.cmd run dev:api` (port 3000), production `npm.cmd start` after build; build/typecheck `npm.cmd run build` / `npm.cmd run typecheck`; health `GET /api/health`.
- **Web:** `src/`; Vite command `npm.cmd run dev:web` (port 5173), build `npm.cmd run build`; API seam is the typed-light `api()` helper at the top of `src/App.tsx`, calling same-origin `/api/*` (Vite proxies to 3000).
- **Mock data:** none. Course source content is original and stored in `server/curriculum.mjs`; no mock API client, mock datasets, duplicate local types package, or mock-state switcher to delete.
- **Routes:** `GET /api/health`, `/api/session`, `/api/catalog`, `/api/progress`, `/api/billing`, `/api/lessons/:id`, `/api/quiz/:domainId`, `/api/attempts`, `/api/admin/lessons`; `POST /api/auth/register`, `/api/auth/login`, `/api/auth/logout`, `/api/progress`, `/api/quiz/submit`, `/api/tutor`, `/api/admin/bootstrap`, `/api/billing/checkout`, `/api/billing/portal`, `/api/billing/webhook`; `PUT /api/admin/lessons/:id`.
- **Database:** local SQLite (`DATABASE_PATH`, default `data/fahan-academy.sqlite`), schema initialization in `server/db.mjs`; no migration framework or PostgreSQL adapter yet. Persistent local learning content/progress requires one API process/replica. Before scaling, migrate to managed PostgreSQL with explicit schema migrations; do not treat the SQLite schema as a production migration.
- **No seed users or seed progress.** The 14 original curriculum lessons are initialized as required course content. There are no seeded accounts, sample questions from the source guide, or seeded entitlements. Schema/setup must not create seed data beyond the required original course.
- **Services:** SQLite local store (Essential, one instance); React/Vite static app + Node API (Essential); Anthropic tutor (Enhancement, server key required); Stripe subscriptions (Enhancement, test key/price/webhook config required; no live payment setup).
